# Website project defaults — 2e Studio

When building or updating websites for this user, unless they explicitly request otherwise:
- Include the exact credit “Designed by 2e Studio” in the footer. Do not invent a studio URL; use plain text unless a verified destination is supplied.
- Design mobile and tablet layouts deliberately to limit unnecessary vertical scrolling. Use accessible swipeable card rows with manual controls, compact grids, or accordions for repeated card groups where appropriate. Keep essential actions visible and avoid autoplay.
- Keep mobile/tablet footers compact: use side-by-side link groups where space allows, reduce excess padding, and preserve readable text, usable touch targets, and essential notices.
- Check phone, tablet, and desktop layouts for overflow and verify interactive controls before delivering a preview.
